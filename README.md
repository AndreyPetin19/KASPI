# Olympiad Prototype

Демонстрационный React/Vite-прототип для школьной олимпиады.

## Что уже работает

- Главная страница в стиле референса.
- «Мой Банк» с тестовыми счетами/суммами.
- Kaspi QR открывает камеру устройства.
- «Госуслуги» → «Удостоверение личности».
- Загрузка демонстрационного изображения документа.
- Загруженное изображение хранится в IndexedDB и остаётся после перезапуска.
- Реквизиты можно вводить вручную; они сохраняются в localStorage.
- «Предъявить документ» показывает QR, ведущий на https://kaspi.kz.
- «Отправить документ» использует системное меню Share, если браузер его поддерживает.
- На всех чувствительных экранах отображается постоянная маркировка «ПРОТОТИП».

## Запуск

```bash
npm install
npm run dev
```

Для камеры на телефоне нужен HTTPS. Проще всего задеплоить проект на Vercel/Netlify или открыть через локальный HTTPS.

## Где менять суммы

Файл `src/main.jsx`, константа `ACCOUNTS`.

## Важно

Используйте только тестовые изображения и тестовые реквизиты.
